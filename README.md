# אוצר המקרא — קונקורדנציה, שורשים ומפת קשרים אינטראקטיבית לתנ"ך

מנוע חיפוש וחקר בלשני מלא לכל **305,517** מופעי המילים, **54,153** הצורות המנוקדות, **1,773** השורשים ו-**23,213** הפסוקים שבכל **39** ספרי התנ"ך — פועל ישירות בדפדפן ללא צורך בשרת.

- **לאתר החי ב-GitHub Pages:** https://ilaykid.github.io/otzar-hamikra/
- **קבצים ליצירה מקומית:**
  - `build_concordance.py` — הפקת טבלת הקונקורדנציה ל-`CSV` ול-`Excel` (`XLSX`)
  - `build_db.py` — בניית מסד הנתונים `tanakh.db` לשרת המקומי `app.py`
  - `build_pages.py` — אריזת קובצי ה-`JSON` המכווצים בתיקייה `docs/data/` עבור GitHub Pages

מקורות טקסט ומורפולוגיה: `openscriptures/morphhb` ו-`openscriptures/HebrewLexicon`.
